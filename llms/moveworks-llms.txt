# Moveworks

> Moveworks is an enterprise agentic AI assistant platform. Its developer platform ("Build with Moveworks" / Agent Studio) exposes REST APIs to send events, drive conversations with the AI Assistant, export analytics data, and receive webhooks, plus customer-hosted gateways (Content, Identity, Knowledge, Forms). All APIs use HTTP Bearer authentication; OAuth 2.0 Client Credentials issues short-lived (60s) access tokens.

## APIs

- [Events API](https://docs.moveworks.com/api-reference/events-api/events-api): Send events to trigger automations and notify employees; OAuth token endpoint.
- [Conversations API](https://docs.moveworks.com/api-reference/conversations-api/conversations-api): Create/manage conversation threads and AI responses (streaming supported).
- [Data API](https://docs.moveworks.com/api-reference/data-api): Export conversations, interactions, plugin calls, plugin resources and users for analytics.
- [Webhook Listeners](https://docs.moveworks.com/api-reference/webhook-listeners): Receive inbound webhook events into Agent Studio listeners.
- [Content Gateway](https://docs.moveworks.com/api-reference/content-gateway/content-gateway): Customer-hosted — serve files/permissions to the AI.
- [Identity Gateway](https://docs.moveworks.com/api-reference/legacy-gateways/identity-gateway): Customer-hosted — resolve user identities.
- [Knowledge Gateway](https://docs.moveworks.com/api-reference/legacy-gateways/knowledge-gateway): Customer-hosted — provide knowledge-base articles.
- [Forms Gateway](https://docs.moveworks.com/api-reference/legacy-gateways/forms-gateway): Customer-hosted — list/submit forms.
